# Signal Registry - Project Notes

This folder stores documentation for the **Signal Registry** web application.

## Project Overview

Signal Registry is a Vue 3 + Vite dashboard application used to manage and monitor signal registration data.

## Tech Stack

- Vue 3
- Vue Router
- Vite
- ESLint + Oxlint
- Prettier

## Local Development

Install dependencies:

```sh
npm install
```

Start development server:

```sh
npm run dev
```

Build for production:

```sh
npm run build
```

Run lint checks:

```sh
npm run lint
```

Format source files:

```sh
npm run format
```
